# Workflow records

This directory retains the current timestamped research summary. Canonical
machine-readable evidence for the reported results is stored under
`outputs/equilibria/corrected_demand_20260916/`.

## Naming convention

- New conversational summaries: `summary_YYYYMMDD_HHMMSS.md`, using Europe/Vienna local time.
- Canonical run manifests: `outputs/equilibria/corrected_demand_20260916/provenance/`.
- Superseded summaries, manifests, and backups: external archive rather than
  the active repository tree.

Summaries are immutable snapshots. Create a new timestamped file for each requested update rather than appending to or replacing an earlier summary.

Historical manifests, backups, and superseded timestamped summaries were
externalized during repository cleanup rather than deleted.
